# Miss & Tell — website concept

An independent concept for PewView's Miss & Tell, prepared for review. This is not an official site.

## Preview

Open `index.html` in a browser. No installation or build is required. All images and site code are local; only watch and social links need internet access.

For a local web preview, run `python3 -m http.server 4173 --bind 127.0.0.1` in this folder and visit http://127.0.0.1:4173.

## GitHub Pages

1. Create a public repository named `Miss-And-Tell-Concept` in the intended GitHub account.
2. Upload this folder's contents (keep `index.html` at the repository root).
3. In repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
4. Wait for the Pages deployment, then use the live URL displayed by GitHub.

No custom domain or paid hosting is needed for a public GitHub Pages repository. Documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editing

- `index.html`: copy, episode titles and links, section content.
- `styles.css`: colors, layouts and responsive styling.
- `app.js`: mobile menu and episode filtering.
- `assets/`: official show logo, episode thumbnails and concept favicon.
- `episode-sources.json`: episode metadata collected from the public show channel on October 1, 2026.

Episodes are a curated snapshot, not a live feed. Update the featured video and cards when new episodes are published. No email collection, analytics, embedded players, or backend is configured.
